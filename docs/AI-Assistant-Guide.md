# AI 助手功能使用指南

## 功能概述

白鹭编辑器集成了 AI 助手功能，支持多种 AI 服务提供商，帮助创作者进行写作辅助、内容生成和创意扩展。

## 主要特性

- **多供应商支持**：OpenAI、Anthropic、自定义 API 端点
- **实时对话**：与 AI 进行连续对话，上下文自动保留
- **内容插入**：一键将 AI 生成的内容插入到编辑器
- **历史记录**：自动保存对话历史，支持清除和重新生成
- **响应式设计**：桌面侧边栏 + 移动端抽屉，适配各种屏幕
- **安全存储**：API 密钥使用 Base64 加密存储在本地

## 快速开始

### 1. 配置 AI 服务

首次使用需要配置 AI 服务：

1. 点击 AI 助手面板右上角的 **设置按钮**（齿轮图标）
2. 在弹出的配置窗口中选择服务提供商
3. 输入 API 密钥
4. 选择模型和参数
5. 点击 **测试连接** 验证配置
6. 点击 **保存** 完成配置

### 2. 开始对话

配置完成后，即可在输入框中输入问题或指令：

```
请帮我写一段关于春天的描述
```

点击发送按钮（或按 Enter），AI 将生成响应。

### 3. 使用生成的内容

- **插入到编辑器**：点击响应内容上方的 "插入" 按钮，内容将自动插入到光标位置
- **复制内容**：点击 "复制" 按钮复制到剪贴板
- **重新生成**：点击 "重新生成" 让 AI 重新生成响应
- **清除历史**：点击面板底部的 "清除历史" 清空对话记录

## 支持的 AI 服务

### OpenAI

**API 基础地址**：`https://api.openai.com/v1`

**支持模型**：
- GPT-4
- GPT-4 Turbo
- GPT-3.5 Turbo
- GPT-4o
- GPT-4o Mini

**获取 API 密钥**：访问 [OpenAI Platform](https://platform.openai.com/api-keys)

### Anthropic

**API 基础地址**：`https://api.anthropic.com/v1`

**支持模型**：
- Claude 3 Opus
- Claude 3 Sonnet
- Claude 3 Haiku

**获取 API 密钥**：访问 [Anthropic Console](https://console.anthropic.com/)

### 自定义端点

支持任何兼容 OpenAI Chat Completions API 格式的服务：

**配置要求**：
- 必须提供 API 端点 URL
- 端点必须支持 `/chat/completions` 路径
- 响应格式需符合 OpenAI 标准

**适用场景**：
- 使用本地部署的 LLM（如 Ollama、vLLM）
- 使用其他云服务商的兼容 API
- 使用代理服务

## 高级用法

### 提示词技巧

1. **明确上下文**：
```
我正在写一个科幻小说，背景是2150年的火星殖民地。请帮我构思一个关于地球与火星贸易的情节。
```

2. **指定风格**：
```
用海明威式的简洁风格，描写一个孤独的夜晚。
```

3. **迭代优化**：
```
上一段太长，请精简到200字以内。
```

4. **角色扮演**：
```
作为一个专业的文学评论家，请点评这段对话的优缺点。
```

### 内容管理

**插入选项**：
- 在光标位置插入
- 替换选中文本
- 追加到文档末尾

**批量操作**：
- 选择多段内容，一次性插入
- 使用快捷键快速操作

**版本控制**：
- AI 生成的内容不会自动保存到文档
- 建议手动保存到版本历史

### 上下文管理

AI 助手会记住最近的对话历史（默认保留最近 20 条消息），这样可以：

- 基于之前的回答继续追问
- 让 AI 了解你的写作风格
- 保持话题的连贯性

**清除上下文**：
- 点击 "清除历史" 完全重置
- 发送新的话题自然切换

### 写作场景应用

1. **灵感启发**：
```
给我5个关于时间旅行悖论的故事创意
```

2. **角色塑造**：

3. **情节扩展**：

4. **对话润色**：

5. **描写增强**：
```
这段描写太平淡，请添加更多感官细节和情感色彩
```

### 效率优化

- **使用模板**：创建常用的提示词模板，快速调用
- **批量生成**：一次请求多个选项，然后挑选最好的
- **分步协作**：让 AI 先生成大纲，再逐段细化
- **自我迭代**：对 AI 的结果进行多轮改进

### 质量控制

- **验证事实**：AI 可能产生幻觉，重要事实需人工核实
- **保持风格一致**：明确指定风格要求
- **逐步完善**：不要一次性要求太多，分步进行
- **人工编辑**：AI 生成的内容需要人工润色和调整

## 配置参数说明

### Temperature（创造性）

- **范围**：0.0 - 2.0
- **低值（0.0-0.3）**：输出更确定、一致，适合事实性内容
- **中值（0.3-0.7）**：平衡创造性和一致性，适合大多数场景
- **高值（0.7-2.0）**：输出更随机、创造性，适合头脑风暴

### Max Tokens（最大长度）

控制 AI 响应的最大长度：
- 短回复：500-1000 tokens
- 中等回复：1000-2000 tokens
- 长回复：2000-4000 tokens

### System Prompt（系统提示）

定义 AI 的角色和行为：
```
你是一位专业的小说写作助手，擅长帮助作家解决创作难题。
你的回答应该简洁、有创意，并且尊重作家的创作意图。
```

自定义系统提示可在 `js/managers/AIManager.js` 中修改。

## 常见问题

### Q: AI 生成的内容会自动保存吗？

A: 不会。AI 生成的内容只在聊天历史中，需要手动点击 "插入" 按钮才会添加到文档。

### Q: 如何保护 API 密钥安全？

A: API 密钥经过 Base64 编码存储在浏览器的 localStorage 中。建议：
- 不要在公共设备上使用
- 定期更换 API 密钥
- 注意浏览器安全设置

### Q: 支持流式输出吗？

A: 当前版本不支持流式输出，完整响应会在生成完成后显示。未来版本会添加此功能。

### Q: 可以使用本地部署的模型吗？

A: 可以。选择 "自定义端点" 选项，配置本地 LLM 的 API 地址（如 Ollama 的 `http://localhost:11434/v1`）。

### Q: 为什么有时候响应很慢？

A: 响应速度取决于：
- 模型选择（GPT-4 比 GPT-3.5 慢）
- 上下文长度
- 网络连接
- 服务商服务器负载

### Q: 如何查看和使用量统计？

A: 当前版本不内置用量统计。建议访问各自服务商的控制台查看：
- OpenAI: https://platform.openai.com/usage
- Anthropic: https://console.anthropic.com/

### Q: 对话历史会同步到云端吗？

A: 不会。对话历史仅存储在本地浏览器中，更换设备或清除浏览器数据会丢失。

## 技术架构

### 模块组成

```
AIManager (业务逻辑)
    ↓
AIConfigManager (配置管理)
    ↓
AIService (API 调用)
    ↓
第三方 AI API (OpenAI/Anthropic/自定义)
```

### 数据流

1. 用户输入 → AIManager 处理
2. 加载配置 → AIConfigManager
3. 构造请求 → AIService
4. 发送请求 → AI API
5. 接收响应 → AIService 解析
6. 显示结果 → AIManager 更新 UI
7. 保存历史 → localStorage

### 事件系统

AI 助手通过事件系统与应用其他部分交互：

- `ai:messageSent` - 发送消息事件
- `ai:stopGeneration` - 停止生成事件
- `ai:insertContent` - 插入内容事件
- `ai:configUpdated` - 配置更新事件
